# 群星映色 · 角色主题包 1.0.0

电栖 1.0.2 的可选离线插件。包含 109 套角色灵感主题，不需要联网、登录或额外运行服务；默认关闭。

| 游戏 | 数量 | 示例 |
| --- | ---: | --- |
| 明日方舟：终末地 | 19 | 祀、提弗洛斯、梨诺、诀、卡缪、弭弗 |
| 明日方舟 | 50 | 阿米娅、凯尔希、斯卡蒂、德克萨斯、令 |
| 绝区零 | 24 | 艾莲、星见雅、妮可、青衣、柏妮思 |
| 少女前线2：追放 | 16 | 黛烟、琼玖、索米、玛绮朵、可露凯 |

每条记录在 `Themes.txt` 单独指定强调色、辅助色、底色、深浅方向和原创配色名称。运行时从这些色种生成 12 个宿主颜色资源，并调整文字和强调色对比度。没有本地图片时使用电路、晶片、节拍、准星四组原创矢量图案；有图片时，列表显示对应角色的立绘缩略图。

插件安装到 `plugins/character-themes/`，只需要 `plugin.json` 与 `PowerHub.CharacterThemes.dll`。从插件页开启，在“设置 → 通用 → 插件主题”筛选游戏、输入角色名或英文 ID 片段并点击选用。列表采用可见条目虚拟化，缩略图最长边 256 像素、最多缓存 16 张；搜索不扫描磁盘。关闭主题包后不会影响系统主题和其他主题插件。

终末地名单核对至 2026-10-20，包含截至「祀」的 12 位特许寻访六星角色：莱万汀、洁尔佩塔、伊冯、洛茜、汤汤、庄方宜、弭弗、卡缪、诀、梨诺、提弗洛斯、祀。19 套主题均可匹配个人单独准备的本地立绘。

角色名字保留中文，游戏分组和控件支持应用的四种语言。没有附带游戏立绘、官方 Logo、语音、字体；配色及几何装饰为本项目设计。属于非官方同好主题，游戏及角色权利归各权利方，MIT 仅适用于本仓库自身代码与原创装饰。

## 独立本地立绘

在主题列表选中角色后，点击“选择立绘文件夹”，指定本地 `artwork` 目录。文件按完整主题 ID 命名，例如 `endfield-si.png`、`arknights-amiya.png`，支持 PNG/JPEG。可为当前角色单独选图、切换显示、设置透明度与左中右位置。图片不随公开仓库或发行包分发，应用不联网获取图片，个人准备的素材不受本仓库 MIT 许可覆盖。
