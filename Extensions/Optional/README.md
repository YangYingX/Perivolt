# 可选插件开发约定

此目录存放电栖独立增强插件源码；[插件总目录](../README.md)列出可用项目。首批交互插件面向 **1.0.8-preview.1 / API 2** 开发预览，公开的 1.0.7 不支持，尚未公开发布插件下载包。

## 范围

| 插件 | 当前功能 | 后续范围 |
| --- | --- | --- |
| [任务栏增强](TaskbarTools) | 悬停多设备概览、滚轮切换设备、读数状态说明及独立概览窗口 | 多显示器增强与自动隐藏实机覆盖待后续迭代 |
| [电量趋势](BatteryHistory) | 本地电量百分比历史、24 小时 / 7 天查询与断点曲线 | 更长时间的实体设备与长期写入验证 |

API 1 的设备读取、提醒和主题保持兼容；API 2 新增 `interactive` 类型，提供设备快照、任务栏弹层、滚轮与独立窗口入口。不要通过反射、注入、全局输入钩子或修改内部窗口绕过契约。主程序保留任务栏基础显示与最小挂钩，增强逻辑、界面、历史采集与存储放在可选插件中。设备快照通常只有电量百分比或档位，不能据此宣称精确功率、能耗或剩余使用时长。

## 开发与分发

1. 一个插件一个子目录，包含项目、`plugin.json` 和说明；稳定保留插件 ID，注明宿主最低版本和 API 版本。
2. 复用宿主已有设备扫描结果，不重复轮询硬件。未安装不运行功能，未启用不加载 DLL。API 2 的初始化、快照更新、界面交互与 `Dispose()` 均在宿主 UI 线程；磁盘读写应异步且有界。API 1 实用插件的 `OnScan` 仍在后台执行。宿主等待在用回调结束后清理，不会强行中断。
3. 界面隐藏时停止动画；历史采集只在插件开启后运行，本地保存，设置有限的保留范围。数据未知或过期时如实显示，不将缓存值冒充实时电量。
4. 独立编译和打包，不加入 `Essentials`、`VendorProtocols` 或默认构建白名单。使用仓库根目录的 `scripts/Build-Plugin.ps1 -Project <项目路径>` 生成独立分发包。
5. 完成后在[插件总目录](../README.md)登记使用说明与下载入口；随插件发布许可、署名和第三方声明，不附带主程序、运行时或用户个人数据。

宿主和插件版本可独立发布。尚未实现或未经验证的能力保持标注为“待开发”，不提供空壳清单让用户误以为已经可用。
