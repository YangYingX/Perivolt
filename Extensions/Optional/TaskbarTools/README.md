# 任务栏增强 · Taskbar Tools 1.1.0

这是独立可选插件，不进入默认构建或安装包。最低兼容电栖 **1.0.8-preview.2**（提供交互插件 **API 3**）开发版宿主；公开发布的 **1.0.7 不支持**此插件。当前尚未发布插件下载包。

## 已实现

- 悬停任务栏电量条，查看多设备电量、连接状态、最近扫描与读数时间。弹出层的定位、显示和关闭由宿主负责。
- 点击已知在线且有有效百分比（含 0%）或电量档位的设备，切换任务栏显示。无效百分比、未读到电量、离线和连接未知的行不可切换。
- 在任务栏电量条上滚动，每累计 120 个滚轮单位切换一台可用设备。向上切换上一台，向下切换下一台；按设备名称、ID 排序循环，以当前显示的设备为起点（包括自动模式）。没有当前可用设备时，第一格选择列表中的第一台可用设备。没有可切换设备时不处理滚轮。
- “自动”恢复宿主的自动选择；选择通过宿主回调保存，不单独写设置文件。
- 从宿主插件页打开 460×440 的独立概览窗口，内容可滚动。重复打开激活已有窗口，关闭后可重新打开。
- 独立概览中的“在所有显示器的任务栏显示”默认开启，只有宿主全局任务栏显示已启用时才创建副屏显示。关闭此选项后保留主屏显示和自动隐藏状态跟踪。
- 按显示器设备名管理副任务栏，复用宿主的绘制、拖动、占用区避让和弹层/滚轮能力；Explorer 重建、任务栏句柄更换或显示布局变化时回收旧显示并恢复新显示。
- 主/副任务栏自动隐藏或只有部分露出时隐藏电量条并关闭弹层，任务栏完整显示后恢复；允许一物理像素边界误差。不在桌面创建悬浮替代，也不会改变 Windows 的自动隐藏或多屏设置。

## 读数的含义

插件只展示宿主提供的设备快照，不额外扫描硬件。多屏管理仅在插件及全局任务栏显示开启时使用两秒轻量原生窗口拓扑轮询；另外按主任务栏 Explorer PID 过滤原生显示/隐藏/位置事件，回调只接收已知任务栏句柄。没有输入钩子、注入或动画。

- 未知电量显示“未读到”，不会补成 0%；0% 是有效读数。
- `UpdatedAt` 未知时明确显示“采样时间未知”；超过五分钟标注“旧读数”，时间异常也单独标注。窗口中的时间文本在新快照或交互时更新。
- Windows 电量/兼容属性及宿主标注的缓存一律显示为“系统属性 / 缓存读数”。其时间仅表示属性读取时间，设备实际报告时间未知，不能当作刚刚从设备收到的电量。
- 本次运行见过、后来未出现在扫描中的设备最多保留 12 台，显示“离线（本次扫描未出现）”，百分比注明“上次”。缺席不等于硬件已确认断连；旧值不会参与滚轮或点击选择。显式离线、连接未知也分别标注。
- 数据来自宿主公开的 `DeviceStatus`，不推断精确能耗或剩余使用时长。停用/退出同步关闭独立窗口并清除视图回调及本次运行的设备记录。

## 本地设置

“在所有显示器的任务栏显示”偏好和各显示器拖动结束时的位置保存在插件数据目录的 `taskbar-tools.json`，最多保留 32 个显示器位置。拖动帧不写盘，写入异步串行并合并待写快照，使用临时文件原子替换。实例持有独立文件租约，停用后的旧写入完成并释放租约后，新实例才读取设置，避免旧实例的尾部写入覆盖新设置。`FlushAsync` 可等待待写入任务，`Dispose` 排队完成清理，不在 UI 线程等待磁盘。目录不可读写时概览会显示提示。

停用或关闭全局任务栏显示会停止拓扑计时器、解绑原生事件并释放所有副屏资源。多个任务栏弹层各自持有视图，关闭时解除按钮回调，不会在另一屏打开弹层时释放仍在使用的视图。

## 开发与安装

项目引用 `../../../PowerHub.csproj`，目标框架为 `net10.0-windows10.0.19041.0`，程序集为 `Perivolt.TaskbarTools.dll`。需先完成 API 3 宿主构建，再使用支持 API 3 的独立打包脚本：

```powershell
.\scripts\Build-Plugin.ps1 -Project Extensions\Optional\TaskbarTools\TaskbarTools.csproj
```

将独立包中的 `taskbar-tools` 文件夹放入宿主 `plugins` 目录，在插件页启用。不要把主程序或 .NET 运行时混入插件包。

界面沿用宿主动态主题资源。文案通过 `L.T` 使用现有翻译，未收录的新文案回退中文；本插件尚未完成四语翻译。
