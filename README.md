# 电栖 · Perivolt

<img src="Assets/powerhub-128.png" alt="电栖 · Perivolt" width="72" />

把外设电量留在托盘和桌面一角，按每台设备自己的阈值提醒充电。

电栖（Perivolt，原 PowerHub）是原生 C# / .NET 10 / WPF 桌面程序。当前 Windows 正式版本为 **1.1.0**。支持 **Windows 10 2004（build 19041）及以上、Windows 11，x64**。发布包自带运行时，无需安装 .NET SDK。1.0.5 起，安装包使用 `Perivolt-Setup-<版本>-x64.exe`，程序与进程名使用 `Perivolt.exe`；为兼容旧设置和插件，设置目录、启动项标识及内部程序集保留 PowerHub。macOS 版仍在开发中，尚未发行。

1.0.8 提供独立的任务栏增强和电量历史插件：悬停查看多设备电量、滚轮切换、副屏任务栏及各屏位置保存，以及本地 24 小时 / 7 天趋势。两款插件按需下载、手动启用，默认安装包和便携包不附带。宿主支持交互插件 API 2/3，并兼容原 API 1 插件；沿用 1.0.7 的波浪填充和简洁卡片样式。详细范围及实机验证边界见[兼容性说明](docs/compatibility.md)和[更新记录](docs/CHANGELOG.md)。

## 1.1 正式版更新

**1.1.0** 合并此前两轮开发预览，带来外设自动化、桌面场景、自由卡片和外设登场卡。已有设置及插件保持兼容，下载入口见下方。

- **外设自动化中心**：从侧栏“自动化”或托盘进入，按“触发事件 → 附加条件 → 顺序动作”编排设备、应用、时间与音频联动。提供耳机、游戏和夜间模板；最多 32 条规则，每条最多 8 个条件、12 个动作，可设置冷却、检查规则、手动执行、暂停及查看记录。首次采样只建立基线，总开关默认暂停。设备断开或应用退出时可自动恢复，另有手动恢复入口；后续手动更改的值会保留。配置步骤、恢复边界及示例见[自动化规则说明](docs/automation.md)。

- **桌面场景**：在“设置 → 桌面卡片”调整主题、布局和显示设备后，输入名称并保存，最多保留 12 个场景。可在设置或托盘的“桌面场景”菜单中切换，支持更新、重命名和删除。场景包含卡片位置、顺序、简洁、半透明、置顶、锁定及吸附选项；充电提醒阈值和设备配色继续沿用原有设置。
- **自由摆放**：卡片布局默认保留集中显示，可切换为每台固定且确认在线的设备一张独立卡片。拖动结束后可吸附屏幕工作区边缘和其他卡片；断线隐藏，重连恢复位置。独立卡片的隐藏按钮只取消该设备的固定；“找回卡片”可启用、解锁并重新排列全部卡片。
- **外设登场卡**：在“设置 → 通用”开关“外设连接时显示登场卡”，默认开启并遵循全局提醒开关。首次成功扫描只建立基线，后续确认连接时显示无声主题卡片；约五秒自动关闭，悬停暂停，点击可进入对应设备设置。短时连接抖动限频，显示和等待中的卡片合计最多三张；未知电量、缓存旧值和 Windows 系统报告分别标注。

设备触发复用已有电量扫描；开启自动化后，只查询规则引用的进程名和本地时间。音频动作使用 Windows 声音接口，不新增联网功能。多显示器、混合 DPI、实体设备连接抖动及不同音频驱动组合仍需进一步实机验证。

## 下载与启动

从 [1.1.0 发行页](https://github.com/YangYingX/Perivolt/releases/tag/v1.1.0) 下载 Windows 安装程序或便携 ZIP，也可通过 [最新发行版](https://github.com/YangYingX/Perivolt/releases/latest) 获取后续更新。独立插件按各自说明下载，不包含在默认安装包和便携包中。v1.0.0–v1.0.5 已转为草稿归档；v1.0.6 及后续发行版保留公开下载，不再随新版发布自动归档。Git 标签和源码历史保留，历史 MIT 授权不受影响。

仓库已更名为 Perivolt。1.0.2 及更早版本的更新检查仍使用旧 API 地址，无法跟随仓库改名后的重定向；请从新发行页手动下载覆盖安装。1.0.3 已修正更新地址，现有设备设置会保留。

- **安装版**：运行 `Perivolt-Setup-1.1.0-x64.exe`，优先选择非系统固定磁盘（如 `D:\Apps\Perivolt`），始终显示目录选择页；没有可用的非系统盘时需要手动选择，不自动回退到 C 盘。无需管理员权限，目录需可写。桌面快捷方式与开机启动均可选。
- **便携版**：完整解压 `Perivolt-1.1.0-win-x64.zip`，运行其中的 `Perivolt.exe`；保留所有 DLL、运行时、`plugins` 和第三方声明文件，不能只复制 EXE。

覆盖安装保留原目录并更新快捷方式与已启用的开机启动命令，已有设置与插件保持兼容。

默认常驻托盘：左键打开面板，右键进入快捷设置。关闭面板后继续监测，完全退出请使用托盘菜单。重复启动会打开已有实例；`--show` 可直接显示面板。

**从旧版升级无需卸载**：1.0.5 安装器会检测原安装目录正在使用的文件，提供自动关闭旧程序的选项，正常退出并保存设置后再覆盖。不要删除旧设置文件。便携版先退出，再将新版完整解压到原目录。1.0.2 及更早版本请按上方说明手动下载。装好 1.0.5 后，后续更新可在应用内直接下载、校验并打开安装向导，沿用当前安装目录。详见[应用内更新](docs/auto-update-plan.md)。

## 可以做什么

- 只展示本次确认连接的外接设备，过滤离线蓝牙、内置设备和虚拟接口；无法读取的电量保留为未知。
- 圆环、条形、沙漏、海洋球和整卡填充五种展示，新设备默认为圆环。条形、沙漏、海洋球、整卡填充可各自调节填充透明度，动效幅度按设备保存；沙漏显示从上往下的落沙。整卡填充关闭动效时末端为圆角，开启动效后末端轻微波动，无需正在充电；0%、100% 和未知电量不产生边界波浪。动画最高 24 fps，隐藏时停止，也可完全关闭。
- 2–10 个可编辑颜色节点，默认 20%、60%、100% 三档。关闭区间过渡时，按上界分档整块使用该档颜色（默认 ≤20%、21–60%、61–100%）；开启后支持线性过渡及图形内部渐变。整体不透明度可按设备调节，圆环也适用。原生主题取色器支持色板、色相、常用色和 HEX 输入，横向色带标明完整的 0%–100% 区间。
- 鼠标、键盘、手柄、耳机、麦克风等设备使用对应图标。每设备独立名称、名称颜色、展示方式、动效、百分比显示、配色和充电提醒，重新连接同一设备后保留偏好。数值可用滑块或紧凑输入框调整，拖动时先预览，停止操作后保存。
- 七种主题：跟随系统、浅色、深色、深海蓝、薰衣草、暖杏日落、森林绿。启用主题插件后会在主题列表中增加选项，选择后才应用；禁用当前主题插件时恢复跟随系统。主题氛围提供鼠标跟随光晕和点击涟漪，可在“设置 → 通用”的主题区域关闭，并遵循全局动效和系统动画设置。
- 统一设置页面，通过横向标签切换提醒、设备外观、桌面卡片和通用选项；顶部固定预览会随所选设备和当前编辑即时变化。桌面卡片支持固定设备、简洁模式、透明背景、置顶与锁定；设置页提供居中的真实卡片镜像，简洁模式压缩行高和上下留白。设备概览支持拖动排序，桌面卡片同步顺序；断开的设备自动隐藏，重连保留顺序，屏外卡片可一键找回。可展开的设置面板有短时动画，关闭动效时立即切换。
- 可配置扫描间隔和重复提醒间隔；充电中、离线及无有效电量时暂停低电提醒。手柄等原生电量档位保留其实际精度。
- 独立“插件”页面，按需开启设备协议、外观及实用插件；另提供开机启动和启动时仅显示托盘选项。
- 默认关闭的自动检查更新：开启后每 12 小时检查项目 GitHub 发行版。点击“下载并安装”可显示下载进度、取消下载，校验通过后直接打开安装向导，保留原安装目录和设置。
- 支持手动预览并上报脱敏诊断，以及默认关闭的失败自动上报。项目接收服务已部署，正式安装包已编入地址；未配置地址的源码构建会禁用上报入口。部署和构建方式见 [诊断接收服务](server/diagnostics-worker/README.md)。
- 主面板打开与关闭使用 180 ms 缩放和淡入淡出，收起过程中可以重新打开；关闭全局动效或系统动画后立即切换，动画完成后停止动画时钟。

## 当前兼容情况

通用读取使用 Windows 电量属性、BLE Battery Service、标准 HID 电池报告和 XInput。默认启用的设备协议插件补充部分 Logitech、Razer、VGN / Weisheng、Compx、AULA、DualSense 与 Steam Controller 协议。

**品牌名称不代表整条产品线已兼容。** 型号、VID/PID、接收器版本和连接模式都必须匹配；同一设备蓝牙可读，不代表其 2.4G 或 USB 模式同样可读。

本机已经实际读到 VGN / Weisheng 键盘的 2.4G 电量、Akko 鼠标的 BLE 电量和蓝牙耳机的 Windows 电量属性。1.0.5 补充 Akko 空影 TAN8 `38EE:000F` 接收器适配，已实际读到 44%；该电量报告不提供鼠标无线在线状态，仅显示接收器连接。G502 X LIGHTSPEED 已在诊断中读到 77%；一副 V9 Turbo+ 已确认可读，另一副的查询时序修复仍待实机复测。其他新增厂商读取器已做报文测试，仍需对应实体设备验证。完整范围、精确硬件限制和适配优先级见 [兼容性说明](docs/compatibility.md)。

## 使用桌面卡片与插件

官方插件源码与独立分发说明统一放在 [Extensions 插件目录](Extensions/README.md)。**1.0.8** 首次公开提供任务栏增强 1.1.0（API 3）与电量历史 1.0.0（API 2）的独立 ZIP，用户自行解压到程序旁的 `plugins` 目录，在插件页重新加载后启用；任务栏增强还需开启全局任务栏电量条。1.0.7 无法加载这两个交互插件，请先升级主程序。多屏、混合 DPI 和自动隐藏仍需更多系统配置的实机验证，新插件文案以中文为主。使用说明与边界见 [Optional](Extensions/Optional/README.md)。

另有独立的[外设快捷中枢](Extensions/Optional/PeripheralHub/README.md)体验版插件，可用快捷键查看电量并控制 Windows 音频输出、音量和通信麦克风静音；它仍是可选预览，不附带于 1.1.0 默认安装包或便携包，实机验证范围见插件说明。

在设置的“桌面卡片”标签中，全部在线设备会直接列出，可逐台勾选显示在桌面；可拖动卡片标题栏调整位置。默认集中显示，也可切换为每台设备独立的自由卡片；简洁、半透明背景、置顶和锁定统一应用于当前卡片。半透明模式保留主题底色以便在复杂背景上阅读。点击“找回卡片”会启用、解锁并重新排列全部卡片；外观与置顶设置保留。显示器布局变化后，程序也会检查标题栏是否仍可拖动。

“充电提醒”与“设备外观”页左上方可选择默认配置或某台在线设备；概览卡片的设置入口会直接选中对应设备，也可以重置为默认配置。顶部预览旁提供“显示百分比”开关，沙漏数字显示在图形右侧，避免遮住落沙。“桌面卡片”与“通用”作用于全局，不显示设备切换栏。名称编辑后按 Enter 或离开输入框保存，清空恢复设备原名；名称颜色选择“自动”时跟随主题。偏好按 Windows 设备身份保存；可靠硬件标识一致时自动合并。两种连接没有共同标识时，可在设备外观的“关联连接方式”中手动关联，共用所选设备的设置；不会仅凭名称或型号自动合并不同的实体设备。

“插件”页默认仅开启**多品牌设备协议包**，极光主题、充满电提醒、定时免打扰分别默认关闭。从 1.0.3 起，群星映色角色主题包独立分发，主程序安装包与便携包不再附带。角色主题插件 1.1.1 提供 135 个独立选项：终末地 19、明日方舟 74、绝区零 26、少女前线2：追放 16，包含异格、职业升变与独立身份；每个选项分别保存配色、背景与透明度，按原角色名也能搜索对应形态。插件本身只含配色与原创几何装饰，角色背景通过独立本地文件夹匹配；开启后点击“选择主题”进入设置，选中才应用。安装本地插件、背景匹配方式和开发接口见 [插件文档](docs/plugins.md)及[角色主题包说明](Extensions/CharacterThemes/README.md)。

已发布的旧版角色主题 ZIP 包含 `plugin.json`、`PowerHub.CharacterThemes.dll`、`README.md` 三个文件；新独立构建另附许可与署名声明。新版生成背景另存于 `Perivolt-CharacterBackgrounds-1.1.1-LocalOnly/artwork`；旧 `Perivolt-CharacterArtwork-LocalOnly` 用于原设身份参考。泥岩背景采用无头盔精二形象，沿用原 `arknights-mudrock` 选项。背景包仅在本地提供，与插件包分开使用。

## 数据与隐私

默认离线运行。更新检查和诊断自动上报分别默认关闭，无需账号登录。用户开启“自动检查更新”后，应用向固定的 GitHub Releases 接口查询版本，每 12 小时一次；更新检查不上传设备和个人设置，关闭开关会取消查询及下载并停止后续检查。用户点击“下载并安装”后从项目发行版下载安装包，校验大小和 SHA256，通过后打开交互安装向导；仍保留浏览器查看发行页的入口。

不使用进程内存注入、远程线程、全局键鼠钩子或自装驱动，按普通用户权限运行。设备电量来自 Windows 接口和精确匹配型号的查询报文，不发送固件升级、DPI、灯光、配对或按键配置命令。

兼容性诊断由用户手动导出，可能包含设备名称、蓝牙地址、容器标识、实例路径及序列号；提交问题前请删除这些唯一标识。仓库与发布包不包含真实设备诊断或个人设置。

诊断上报使用单独的白名单报告，不上传上述原始文件。手动上报先显示完整发送内容；启用自动上报后，同类电量读取失败连续出现三次才发送，相同报告在本机 24 小时内只自动发送一次。报告经 Cloudflare Workers 接收，由项目 GitHub App 提交到公开 Issue；内容限于应用/系统版本、非唯一的 VID/PID、接口规格、协议状态及已知电量查询字段，不含设备名称、序列号、MAC、容器标识、路径或个人设置。服务再次验证字段，七天内复用同类 Issue，且限制请求频率。机器人密钥仅存于 Workers secrets；接收服务处理网络请求时可见 IP，仅保存加盐哈希及限频计数，不写入 Issue。关闭自动上报会取消正在发送的自动报告并停止后续自动发送，已经发布到 GitHub 的 Issue 不会随之删除。

日常设置写入 `%LOCALAPPDATA%\PowerHub\settings.json`，与程序安装目录分开，因此移动或升级程序不会丢失设备名称和偏好。首次启动 1.0.1 会尝试导入 1.0.0 原工作区、程序目录或旧默认安装目录内的 `artifacts\data\settings.json`；已有新设置不覆盖，原文件保留。可通过 `--data-dir <目录>` 指定数据位置。卸载程序会移除安装文件和开机启动项，保留用户设置。插件是同进程的本地 DLL 扩展，没有权限沙箱；第三方插件默认关闭，其行为不在内置代码的离线核查范围内，请仅启用信任来源的插件。

## 从源码构建

```powershell
# 编译核心和内置插件
.\scripts\Build.ps1

# 生成自带运行时的发布目录 dist\PowerHub
.\scripts\Build.ps1 -Publish

# 独立构建一个可选插件，不放进默认输出
.\scripts\Build-Plugin.ps1 -Project .\Extensions\CharacterThemes\CharacterThemes.csproj

# 使用本地 Inno Setup 编译器生成安装器
.\scripts\Build-Installer.ps1
```

首次构建可由 `scripts\Bootstrap.ps1` 下载微软 SDK 并校验 SHA512，SDK 和依赖缓存保存在项目内 `.tools`。安装器构建另外需要 `.tools\inno\compiler\ISCC.exe`，只负责打包已有发布目录，不会安装或启动程序。

开发诊断示例：

```powershell
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --self-check
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --scan --output .\artifacts\scan.json
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --screenshot .\artifacts\settings.png --page settings --theme Dark
```

`--no-ble` 可用于扫描时跳过主动 GATT 电量查询。截图模式使用隔离设置，不触发实际提醒或改写日常偏好。请勿将本机扫描结果提交到公开仓库。
