# 电栖 · Perivolt

<img src="Assets/powerhub-128.png" alt="电栖 · Perivolt" width="72" />

把外设电量留在托盘和桌面一角，按每台设备自己的阈值提醒充电。

电栖（Perivolt，原 PowerHub）是原生 C# / .NET 10 / WPF 桌面程序。当前稳定发行版为 **1.0.1**，本分支为 **1.0.2 开发预览**。支持 **Windows 10 2004（build 19041）及以上、Windows 11，x64**。发布包自带运行时，无需安装 .NET SDK。为兼容覆盖升级，程序文件名、设置目录、启动项标识与 GitHub 仓库地址暂时保留 PowerHub。

开发预览新增：简体中文、繁體中文、English、日本語即时切换；独立任务栏左端电量条；锁定桌面卡片时鼠标穿透并保留解锁按钮；整张设备卡片按电量填充与文字反色描边；不同连接方式的可撤销设备关联。设置入口和限制见[开发预览说明](docs/perivolt-preview.md)。预览包不代表 1.0.2 正式发布，自动下载安装仍按[既有计划](docs/auto-update-plan.md)另行实现。

## 下载与启动

从 [1.0.1 发行页](https://github.com/YangYingX/PowerHub/releases/tag/v1.0.1) 下载 Windows 安装程序或便携 ZIP，也可通过 [最新发行版](https://github.com/YangYingX/PowerHub/releases/latest) 获取后续更新。

- **安装版**：运行 `PowerHub-Setup-1.0.1-x64.exe`，优先选择非系统固定磁盘（如 `D:\Apps\PowerHub`），始终显示目录选择页；没有可用的非系统盘时需要手动选择，不自动回退到 C 盘。无需管理员权限，目录需可写。桌面快捷方式与开机启动均可选。
- **便携版**：完整解压 ZIP，运行其中的 `PowerHub.exe`；保留同目录的 `plugins` 和第三方声明文件。

默认常驻托盘：左键打开面板，右键进入快捷设置。关闭面板后继续监测，完全退出请使用托盘菜单。重复启动会打开已有实例；`--show` 可直接显示面板。

**从 1.0.0 升级无需卸载**：先从托盘退出旧程序，运行新版安装器并选择原安装目录覆盖安装；不要删除旧设置文件。便携版先退出，再将新版完整解压到原目录。1.0.0 开启更新检查后会提示 1.0.1，但不能自动下载安装。自动下载安装计划见[下一版更新计划](docs/auto-update-plan.md)。

## 可以做什么

- 只展示本次确认连接的外接设备，过滤离线蓝牙、内置设备和虚拟接口；无法读取的电量保留为未知。
- 圆环、条形、沙漏、海洋球和整卡填充五种展示，新设备默认为圆环。条形、沙漏、海洋球、整卡填充可各自调节填充透明度，动效幅度按设备保存；沙漏显示从上往下的落沙。动画最高 24 fps，隐藏时停止，也可完全关闭。
- 2–10 个可编辑颜色节点，默认 20%、60%、100% 三档。关闭区间过渡时，按上界分档整块使用该档颜色（默认 ≤20%、21–60%、61–100%）；开启后支持线性过渡及图形内部渐变。整体不透明度可按设备调节，圆环也适用。原生主题取色器支持色板、色相、常用色和 HEX 输入，横向色带标明完整的 0%–100% 区间。
- 鼠标、键盘、手柄、耳机、麦克风等设备使用对应图标。每设备独立名称、名称颜色、展示方式、动效、百分比显示、配色和充电提醒，重新连接同一设备后保留偏好。数值可用滑块或紧凑输入框调整，拖动时先预览，停止操作后保存。
- 七种主题：跟随系统、浅色、深色、深海蓝、薰衣草、暖杏日落、森林绿。启用主题插件后会在主题列表中增加选项，选择后才应用；禁用当前主题插件时恢复跟随系统。
- 统一设置页面，通过横向标签切换提醒、设备外观、桌面卡片和通用选项；顶部固定预览会随所选设备和当前编辑即时变化。桌面卡片支持固定设备、简洁模式、透明背景、置顶与锁定；设置页提供居中的真实卡片镜像，简洁模式压缩行高和上下留白。设备概览支持拖动排序，桌面卡片同步顺序；断开的设备自动隐藏，重连保留顺序，屏外卡片可一键找回。可展开的设置面板有短时动画，关闭动效时立即切换。
- 可配置扫描间隔和重复提醒间隔；充电中、离线及无有效电量时暂停低电提醒。手柄等原生电量档位保留其实际精度。
- 独立“插件”页面，按需开启设备协议、外观及实用插件；另提供开机启动和启动时仅显示托盘选项。
- 默认关闭的自动检查更新：开启后每 12 小时检查项目 GitHub 发行版，新版本由用户选择下载和安装。
- 主面板打开与关闭使用 180 ms 缩放和淡入淡出，收起过程中可以重新打开；关闭全局动效或系统动画后立即切换，动画完成后停止动画时钟。

## 当前兼容情况

通用读取使用 Windows 电量属性、BLE Battery Service、标准 HID 电池报告和 XInput。默认启用的设备协议插件补充部分 Logitech、Razer、VGN / Weisheng、Compx、AULA、DualSense 与 Steam Controller 协议。

**品牌名称不代表整条产品线已兼容。** 型号、VID/PID、接收器版本和连接模式都必须匹配；同一设备蓝牙可读，不代表其 2.4G 或 USB 模式同样可读。

本机已经实际读到 VGN / Weisheng 键盘的 2.4G 电量、Akko 鼠标的 BLE 电量和蓝牙耳机的 Windows 电量属性。其他新增厂商读取器已做报文测试，仍需对应实体设备验证。**Akko `38EE:000F` 接收器私有电量协议尚未确认。** 完整范围、精确硬件限制和适配优先级见 [兼容性说明](docs/compatibility.md)。

## 使用桌面卡片与插件

在设置的“桌面卡片”标签中，全部在线设备会直接列出，可逐台勾选显示在桌面；可拖动卡片标题栏调整位置。简洁、半透明背景、置顶和锁定控制整个桌面容器，半透明模式保留主题底色以便在复杂背景上阅读。点击“找回卡片”会启用并解锁卡片，将其移回主屏右上角；外观与置顶设置保留。显示器布局变化后，程序也会检查标题栏是否仍可拖动。

“充电提醒”与“设备外观”页左上方可选择默认配置或某台在线设备；概览卡片的设置入口会直接选中对应设备，也可以重置为默认配置。顶部预览旁提供“显示百分比”开关，数字在图形中央显示，包括沙漏样式。“桌面卡片”与“通用”作用于全局，不显示设备切换栏。名称编辑后按 Enter 或离开输入框保存，清空恢复设备原名；名称颜色选择“自动”时跟随主题。偏好按 Windows 设备身份保存；可靠硬件标识一致时自动合并。两种连接没有共同标识时，可在设备外观的“关联连接方式”中手动关联，共用所选设备的设置；不会仅凭名称或型号自动合并不同的实体设备。

“插件”页默认仅开启**多品牌设备协议包**，极光主题、充满电提醒、定时免打扰分别默认关闭。安装本地插件、选项格式和开发接口见 [插件文档](docs/plugins.md)。

## 数据与隐私

默认离线运行。应用及随包内置插件不包含遥测、账号登录、云端同步或远程图标。只有用户开启“自动检查更新”后，应用才向固定的 GitHub Releases 接口查询版本，每 12 小时一次；不上传设备和个人设置，关闭开关会取消正在进行的查询并停止后续检查。发现新版仅提示，用户点击“查看新版本”后通过浏览器下载，不静默执行安装程序。

不使用进程内存注入、远程线程、全局键鼠钩子或自装驱动，按普通用户权限运行。设备电量来自 Windows 接口和精确匹配型号的查询报文，不发送固件升级、DPI、灯光、配对或按键配置命令。

兼容性诊断由用户手动导出，可能包含设备名称、蓝牙地址、容器标识、实例路径及序列号；提交问题前请删除这些唯一标识。仓库与发布包不包含真实设备诊断或个人设置。

日常设置写入 `%LOCALAPPDATA%\PowerHub\settings.json`，与程序安装目录分开，因此移动或升级程序不会丢失设备名称和偏好。首次启动 1.0.1 会尝试导入 1.0.0 原工作区、程序目录或旧默认安装目录内的 `artifacts\data\settings.json`；已有新设置不覆盖，原文件保留。可通过 `--data-dir <目录>` 指定数据位置。卸载程序会移除安装文件和开机启动项，保留用户设置。插件是同进程的本地 DLL 扩展，没有权限沙箱；第三方插件默认关闭，其行为不在内置代码的离线核查范围内，请仅启用信任来源的插件。

## 从源码构建

```powershell
# 编译核心和内置插件
.\scripts\Build.ps1

# 生成自带运行时的发布目录 dist\PowerHub
.\scripts\Build.ps1 -Publish

# 使用本地 Inno Setup 编译器生成安装器
.\scripts\Build-Installer.ps1
```

首次构建可由 `scripts\Bootstrap.ps1` 下载微软 SDK 并校验 SHA512，SDK 和依赖缓存保存在项目内 `.tools`。安装器构建另外需要 `.tools\inno\compiler\ISCC.exe`，只负责打包已有发布目录，不会安装或启动程序。

开发诊断示例：

```powershell
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --self-check
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --scan --output .\artifacts\scan.json
.\.tools\dotnet\dotnet.exe .\bin\Debug\net10.0-windows10.0.19041.0\PowerHub.dll --screenshot .\artifacts\settings.png --page settings --theme Dark
```

`--no-ble` 可用于扫描时跳过主动 GATT 电量查询。截图模式使用隔离设置，不触发实际提醒或改写日常偏好。请勿将本机扫描结果提交到公开仓库。
