# 更新记录

## 1.0.1 · 设置与桌面体验改进（测试中）

- 原生主题取色器：饱和度与亮度面板、色相条、常用色、HEX 输入及新旧颜色预览，设备名称和电量配色共用。
- 设置页重组为横向标签，顶部选择在线设备或默认配置；概览卡片提供直达入口。阈值与节点位置同时提供滑块和紧凑输入框。
- 每设备独立展示方式、动画、百分比显示、配色、提醒阈值和重复间隔；支持恢复默认配置，重连保留偏好。
- 多节点线性渐变支持 2–10 个节点，可分别设位置、颜色和相邻区间是否过渡；随电量变色与图形内渐变由独立开关控制。
- 默认配色采用 20%、60%、100% 三档；关闭过渡的区间按上界档位整块显示纯色。配色面板新增横向区间预览和整体不透明度，重置配色可重新使用三档默认值。
- 设置顶部固定显示所选设备的实时外观，滑动编辑配色与透明度时同步预览；复选框鼠标点击不再出现额外外圈。
- 条形、沙漏和海洋球的填充透明度分别保存，动效幅度按设备调节；沙漏显示上下沙堆与向下流沙，新设备默认为圆环。
- 概览支持拖动排序并保存，桌面卡片使用同一顺序；桌面设置的预览直接镜像真实卡片，电量、布局和配色保持一致。
- 简洁桌面卡片进一步缩小设备行高度与上下留白，宽度保持不变；真实镜像在预览区居中显示。
- 桌面卡片页直接列出全部在线设备以便逐台固定；桌面卡片与通用页隐藏设备选择栏。百分比开关移至固定预览旁，沙漏数字移到图形外侧。
- 半透明卡片保留主题底色，提高复杂背景上的辨识度；修正深海蓝等深色主题下开关文字颜色。设备搜索保留滚动条占位，避免过滤后内容宽度跳动。
- 卡片标题栏提供锁定／解锁按钮；锁定时禁止拖动并禁用打开与隐藏按钮，锁定按钮始终可用。
- 修正主题插件覆盖主题选择的问题：启用仅增加主题选项，明确选择后才生效，禁用当前插件时回退到跟随系统。
- 对齐输入框与固定设备列表；修正复选框勾号偏移与输入框重复内边距，补齐键盘焦点提示及矢量窗口图标。
- 高级选项提供 180 ms 展开收起动画；快速反向操作和关闭动效均可用，拖动滑块不重建设置面板。
- 安装器优先推荐非系统固定磁盘，始终提供目录选择，没有可用候选时要求手动选择。
- 设置固定保存在当前用户应用数据目录，导入旧版设置时保留原文件并避免覆盖新设置。
- 新增“找回卡片”，可恢复屏外卡片；显示器布局变化时按物理坐标检查可操作的标题栏，不再每次刷新重套旧位置。

## 1.0.0 · 首次公开发行

- Windows 托盘电量监测与独立桌面卡片，支持简洁、透明、置顶与锁定。
- 鼠标、键盘、手柄、耳机及麦克风类型图标；逐设备自定义名称、名称颜色、提醒阈值与开关，断开后隐藏并保留偏好。
- 四种电量展示、充电动效、七种主题、分电量区间的纯色或渐变配色。
- Windows、BLE、标准 HID、XInput 通用读取，以及默认内置的多品牌协议插件。
- 极光主题、充满电提醒与定时免打扰三个可选插件；所有插件支持独立开关。
- 原生 WPF 界面，隐藏时停止动画，拖动阈值滑块时仅更新预览，后台查询有超时控制。
- 当前用户安装程序、便携包和可选开机启动；保留 MIT 与第三方许可。
- 默认离线；自动检查更新需手动开启，只检查本项目 GitHub 正式发行版，安装由用户选择。

协议支持按具体型号与连接方式划分。除本机 VGN / Weisheng 键盘、Akko 鼠标 BLE 与蓝牙耳机外，新增厂商读取器尚需更多实体设备验证。详见[兼容性说明](compatibility.md)。
