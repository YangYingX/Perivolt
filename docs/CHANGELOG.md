# 更新记录

## 1.1.1 · 诊断上报与接收器兼容修复

Windows 正式版，发布标签为 `v1.1.1`。安装包为 `Perivolt-Setup-1.1.1-x64.exe`，便携包为 `Perivolt-1.1.1-win-x64.zip`，均自带运行时，保留原有设置和插件。macOS 版仍在开发中，不随本次发行发布。

- 修复诊断接收服务对 GitHub 新格式令牌的误拒绝，以及 Cloudflare 不支持的请求重定向选项；用户手动上报与 GitHub Issue 已实际验证成功，现有限流规则保持不变。
- 客户端区分网络、超时、限流、报告校验和 GitHub 提交失败，显示具体原因及 HTTP 状态；在数据目录的 `logs/diagnostic-upload.log` 保存最多 64 KiB 的脱敏结果记录，不含报告正文、设备标识或凭证。响应读取限制 8 KiB，整体超时覆盖响应体。
- 随包设备协议插件升级为 1.0.6。罗技短报告无响应时，可通过同接收器经描述符验证的长报告通道重试相同只读查询；明确处理 HID++ 1.0 `UNKNOWN_DEVICE (08)`，保留原总时间预算，不扩大槽位探测。
- 通用可移除 USB 节点不再统一标成无线接收器，减少普通 USB 设备的电量失败误报；精确纠正 `1532:024E`（有线 BlackWidow V3）被鼠标模拟接口误分类的问题，未知设备仍保留在设备列表及诊断中。
- 迈从 V9 Turbo+ `3837:600A` 的部分接收器仍出现查询超时，尚未确认解决；罗技长报告回退仍需对应实体设备复测。耳机问题需使用“兼容性诊断 → 导出诊断”提供完整查询阶段，不能仅凭脱敏报告的 `timeout` 判断根因。
- 已完成客户端诊断 43 项场景与 449 条断言、连接分类 24 项、罗技协议 26 项及实际 workerd 12 项回归；保留默认离线、自动上报默认关闭与原有默认插件范围。临时测试源码及输出在验证后删除。

## 1.1.0 · 外设自动化与桌面场景

Windows 正式版，发布标签为 `v1.1.0`。安装包为 `Perivolt-Setup-1.1.0-x64.exe`，便携包为 `Perivolt-1.1.0-win-x64.zip`，下载见 [1.1.0 发行页](https://github.com/YangYingX/Perivolt/releases/tag/v1.1.0)。合并下方 preview.1 和 preview.2 的功能，保留已有设置、插件兼容、作者署名和许可边界。macOS 版仍在开发中，未随本次发行发布。

- 外设自动化中心支持设备连接、断开、电量、充电、应用与每日时间触发，可组合条件并按顺序执行桌面场景和 Windows 音频等动作。提供耳机、游戏、夜间模板、规则检查、冷却、暂停及最多 200 条本机执行记录；最多 32 条规则，每条最多 8 个条件、12 个动作。总开关默认暂停，首次采样只建立基线。
- 连接或应用启动规则可在对应结束时恢复，也可手动恢复单条或全部配置；保留后续手动更改，支持部分失败、离线重试及重叠规则的延迟恢复。恢复点限本次运行，正常退出尝试恢复，强制退出不能保证还原。步骤和边界见[自动化规则说明](automation.md)。
- 桌面场景可保存最多 12 组主题、卡片布局、显示设备与外观，在设置和托盘切换；自由摆放让每台固定且在线的设备拥有独立卡片，支持拖动吸附、断线隐藏、重连保留位置和找回全部卡片。默认继续使用集中布局。
- 外设登场卡在确认连接后无声展示，首次扫描不提示；约五秒关闭、悬停暂停，并对连接抖动限频。主题氛围增加鼠标跟随光晕和点击涟漪，遵循动效设置。新增界面和状态文案覆盖简体中文、繁体中文、英文及日文。
- 默认插件分发范围保持不变。外设快捷中枢为独立可选体验版，不附带于主程序安装包或便携包；任务栏增强、电量历史和角色主题仍按各自说明独立分发。
- 已完成构建、自检、规则及恢复边界、真实 WPF 场景布局、编辑器与模板回归、暗浅主题和四语言界面检查。音频恢复使用模拟状态验证，系统音频接口仅做读取检查；真实音频写入、不同驱动、多屏混合 DPI 和实体设备连接抖动仍需更多实机覆盖。临时测试项目均在验证后删除。

- 设备连接和应用启动规则可在对应结束时自动恢复；也可手动恢复单条或全部配置。恢复按实际修改字段和端点处理，保留后续手动改动；其他规则仍占用相同设置时延迟恢复。正常退出时尝试恢复。恢复点只保存在本次运行内存中，执行历史在本机最多保留 200 条并可清空。
- 新控件及状态文案支持四种语言。默认音频输出切换仍依赖系统可用的 COM 接口，无法保证所有 Windows／驱动组合；真实音频写入、多屏混合 DPI 和实体连接抖动仍需实机覆盖。使用步骤与边界见[自动化规则说明](automation.md)。
- 已验证触发基线、条件组合、冷却、顺序动作、暂停、部分失败、重叠规则恢复、离线重试、历史保存和真实 WPF 场景布局；规则编辑器及三种模板已完成回归，暗浅主题截图已检查。音频恢复使用模拟状态验证，系统音频接口仅做读取检查；临时测试项目均在验证后删除。
