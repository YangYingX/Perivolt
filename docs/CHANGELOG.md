## 1.0.5 · 应用内更新、诊断上报与设备修复

发布标签为 `v1.0.5`。安装包改名为 `Perivolt-Setup-1.0.5-x64.exe`，程序与进程名改为 `Perivolt.exe`；已有设置、插件和安装身份保持兼容，无需先卸载。

- 新增应用内“下载并安装”：自动检查默认关闭，开启后每 12 小时检查正式发行版；点击后下载并验证大小、SHA256 与 EXE 格式，保存设置、打开安装向导并正常退出。支持进度与取消，已安装版沿用原目录并显示目录确认页，自定义数据目录传给安装后启动、快捷方式和此次升级保留的开机启动命令。
- 安装器支持正常关闭正在运行的旧程序；完善托盘“退出”的窗口、卡片和后台任务清理，并缩小托盘右键菜单及子菜单间距。
- 修正 Logitech G502 X LIGHTSPEED 原装接收器的设备识别与电量解析，诊断已实际读到 77%。
- 调整迈从 V9 Turbo+ 查询时序：发送前准备输入监听，写入与响应分别计时，补充阶段诊断；一副已确认可读，另一副超时问题的修复仍待受影响电脑实机复测。
- 新增 Akko 空影 TAN8 `38EE:000F` 2.4G 接收器的精确只读电量适配，已实际读到 44%；协议未提供鼠标无线在线标志，连接状态仅代表接收器。
- 新增手动预览脱敏诊断并上报至公开 GitHub Issue；失败自动上报默认关闭，开启后同类读取连续失败三次才发送，本机 24 小时去重。报告通过已部署的 Cloudflare Workers 和项目 GitHub App 接收，不上传原始诊断文件及设备唯一标识。

应用内更新通过 165 项下载、安装启动、快捷方式及界面检查，并完成真实正式发行包下载和 SHA256 校验；诊断功能通过 129 项本地检查及线上健康/无效请求验证。未在用户电脑执行生产安装器，未上传真实诊断或创建测试 Issue，首次真实报告的完整创建仍待用户预览后验证。临时测试文件已删除。

## 1.0.4 · LT95 与 V9 Turbo 电量适配

发布标签为 `v1.0.4`。退出旧程序后覆盖安装或完整解压，保留已有设备设置；1.0.2 及更早版本请从[发行页](https://github.com/YangYingX/Perivolt/releases/tag/v1.0.4)手动下载。

- 补充迈从 V9 Turbo 接收器 `3837:600A`（系统名称 V9 Turbo+）的旧版 Report `55` 查询，限定 `FF90/0001` 厂商集合，读取电量、充电及休眠状态。
- 新增狼途 LT95 的独立只读电量协议，精确限定 `05AC:024F`、`LT95PRO-2.4G`、`MI_03`、`FF60/0061`；不套用原 Shinetek 键盘协议，不扩大到同 VID/PID 的其他型号。
- LT95 的零值与超范围响应保持未知，充电状态未知；连接状态仅代表接收器，协议不提供独立键盘无线在线标志。
- 已知报告编号可从 HID 值或按钮能力中确认，避免合法厂商报告因描述符类型不同被拒绝。诊断补充输入/输出长度及输入、输出、Feature 报告编号和字段格式。
- 两款适配已完成官方协议核对、94 项报文/匹配检查及原版 1.0.2 的插件加载验证，仍待用户实体设备实读确认。临时测试文件已删除。

## 1.0.3 · 任务栏适配与充电状态

发布标签为 `v1.0.3`。1.0.2 及更早版本请从[新发行页](https://github.com/YangYingX/Perivolt/releases/tag/v1.0.3)手动下载，退出旧程序后覆盖安装或完整解压，保留已有设备设置。

- 任务栏电量条适配上、下、左、右四边及不同 DPI 缩放，自动避让开始按钮、应用按钮和通知区域；空闲空间不足或布局暂时不可识别时隐藏并等待恢复。
- 电量条支持沿任务栏拖动并保存位置，“左侧间距”改为按任务栏方向计算的“起始偏移”；窄空间使用紧凑布局，图标、文字、进度条和圆角随系统明暗、高对比度及 Windows 版本调整。
- 调整托盘右键菜单的所属窗口、前台焦点与延迟打开时序，处理右键后菜单一闪即关的问题；原问题现场仍待用户复测。
- 电量图形和整卡填充补充充电闪电标记，充电时显示呼吸及流光动效；概览的底色填充改为淡色背景和底部细进度条。充电状态优先显示“正在充电”，单独提示低电量提醒已暂停。动效继续遵循全局及每设备设置，隐藏时停止。
- GitHub 仓库更名为 `YangYingX/Perivolt`，同步文档和检查更新接口。已发布的 1.0.2 及更早版本不跟随旧 API 的重定向，需要手动下载覆盖安装。
- 群星映色改为独立可选插件，主程序发布构建和安装器排除该插件；本地开发预览仍可使用。角色主题包需单独安装，立绘仍由用户在本地单独准备。

预览已验证 Windows 11 本机任务栏挂载及模拟托盘菜单交互；Windows 10 实机、不同任务栏布局和用户遇到的右键菜单闪退现场仍需复测。

## 1.0.2 · 电栖、多语言与角色主题

发布标签为 `v1.0.2`。1.0.0 / 1.0.1 用户可通过已开启的更新检查发现新版，选择原目录覆盖安装并保留设置；无需先卸载。当前不会自动下载或静默安装。

- 更名为“电栖 · Perivolt”，新增多尺寸原创图标与完整版本显示；保留旧安装身份和数据目录。
- 内置简体中文、繁體中文、English、日本語，即时切换并记忆选择。
- 群星映色可选插件提供四款游戏共 109 套角色配色、游戏筛选和角色搜索。启用只增加选项，选择后才应用。
- 支持独立本地立绘文件夹及单角色选图、透明度和位置设置。图片异步按需解码，最长边限制为 1600 像素；公开源码及发行包不包含游戏图片，不自动下载素材。
- 立绘覆盖整个窗口，侧栏和页头保留半透明底色，设置卡片向角色一侧渐透，主题选项卡片也使用半透明底色；角色主题列表使用对应立绘缩略图，按可见项加载并限制缓存数量。「年」配色调整为炭黑、朱红和暖金。
- 通过任务栏真实子窗口显示电量，取消置顶桌面覆盖实现；不向 Explorer 注入 DLL，不申请系统保留槽位，仍需设置左侧间距避开现有按钮。
- 桌面卡片锁定后允许点击穿透，并保留单独的解锁入口；新增整卡填充样式，移除反色文字描边。
- 蓝牙与 2.4G 缺少共同硬件身份时可手动关联，保留并共用所选配置；不会仅按同名或同型号自动合并设备。
- 协议包扩展 MCHOSE、LANGTU、SteelSeries、Corsair、HyperX 等精确协议族，覆盖范围与尚未验证设备见兼容性文档。
- 自带运行时改为文件夹部署，避免单文件临时提取；手动首次启动显示面板，加入早期启动日志和独立诊断脚本。
- 立绘主题统一设置区的面板、标签栏、输入框、下拉框和角色列表底色透明度；文字及图标不降低透明度。
- 下拉菜单单独采用接近不透明的主题底色，避免角色列表文字透入选项；精简立绘面板说明。
- 滚动条改为细圆角半透明滑块，悬停与拖动时加深，内容无需滚动时隐藏滑块并保留占位。
- 刷新设备电量时直接更新数值及填充，不重新播放增长动画；持续的流沙、波浪等样式动效保留。整卡填充与对应预览按从左向右的填充方向渐变。
- 针对启动日志中的 Windows CET 支持不完整错误，通过项目级 `CetCompat=false` 生成兼容启动程序；不修改系统的防护策略。本程序因此不带 CET 兼容标记。

收到的 1.0.1 启动日志已定位到 CET 兼容性导致的运行时退出，兼容构建仍待受影响电脑复测。新增厂商读取器、不同系统的任务栏布局仍需对应实机验证。

## 1.0.1 · 设置与桌面体验改进

发布标签为 `v1.0.1`，1.0.0 用户开启更新检查后可收到新版提示。安装器支持覆盖原目录升级，无需卸载。自动下载安装留待下一版实现，见[计划](auto-update-plan.md)。

- 原生主题取色器：饱和度与亮度面板、色相条、常用色、HEX 输入及新旧颜色预览，设备名称和电量配色共用。
- 设置页重组为横向标签，顶部选择在线设备或默认配置；概览卡片提供直达入口。阈值与节点位置同时提供滑块和紧凑输入框。
- 每设备独立展示方式、动画、百分比显示、配色、提醒阈值和重复间隔；支持恢复默认配置，重连保留偏好。
- 多节点线性渐变支持 2–10 个节点，可分别设位置、颜色和相邻区间是否过渡；随电量变色与图形内渐变由独立开关控制。
- 默认配色采用 20%、60%、100% 三档；关闭过渡的区间按上界档位整块显示纯色。配色面板新增横向区间预览和整体不透明度，重置配色可重新使用三档默认值。
- 设置顶部固定显示所选设备的实时外观，滑动编辑配色与透明度时同步预览；复选框鼠标点击不再出现额外外圈。
- 条形、沙漏和海洋球的填充透明度分别保存，动效幅度按设备调节；沙漏显示上下沙堆与向下流沙，新设备默认为圆环。
- 概览支持拖动排序并保存，桌面卡片使用同一顺序；桌面设置的预览直接镜像真实卡片，电量、布局和配色保持一致。
- 简洁桌面卡片进一步缩小设备行高度与上下留白，宽度保持不变；真实镜像在预览区居中显示。
- 桌面卡片页直接列出全部在线设备以便逐台固定；桌面卡片与通用页隐藏设备选择栏。百分比开关移至固定预览旁，沙漏数字统一在图形中央显示。
- 半透明卡片保留主题底色，提高复杂背景上的辨识度；修正深海蓝等深色主题下开关文字颜色。设备搜索保留滚动条占位，避免过滤后内容宽度跳动。
- 卡片标题栏提供锁定／解锁按钮；锁定时禁止拖动并禁用打开与隐藏按钮，锁定按钮始终可用。
- 修正主题插件覆盖主题选择的问题：启用仅增加主题选项，明确选择后才生效，禁用当前插件时回退到跟随系统。
- 对齐输入框与固定设备列表；修正复选框勾号偏移与输入框重复内边距，补齐键盘焦点提示及矢量窗口图标。
- 高级选项提供 180 ms 展开收起动画；快速反向操作和关闭动效均可用，拖动滑块不重建设置面板。
- 主面板打开和关闭使用 180 ms 缩放与淡入淡出；支持收起中重新打开，完成后移除动画时钟，退出前提交尚未保存的编辑。
- 安装器优先推荐非系统固定磁盘，始终提供目录选择，没有可用候选时要求手动选择。
- 设置固定保存在当前用户应用数据目录，导入旧版设置时保留原文件并避免覆盖新设置。
- 新增“找回卡片”，可恢复屏外卡片；显示器布局变化时按物理坐标检查可操作的标题栏，不再每次刷新重套旧位置。

## 1.0.0 · 首次公开发行

- Windows 托盘电量监测与独立桌面卡片，支持简洁、透明、置顶与锁定。
- 鼠标、键盘、手柄、耳机及麦克风类型图标；逐设备自定义名称、名称颜色、提醒阈值与开关，断开后隐藏并保留偏好。
- 四种电量展示、充电动效、七种主题、分电量区间的纯色或渐变配色。
- Windows、BLE、标准 HID、XInput 通用读取，以及默认内置的多品牌协议插件。
- 极光主题、充满电提醒与定时免打扰三个可选插件；所有插件支持独立开关。
- 原生 WPF 界面，隐藏时停止动画，拖动阈值滑块时仅更新预览，后台查询有超时控制。
- 当前用户安装程序、便携包和可选开机启动；保留 MIT 与第三方许可。
- 默认离线；自动检查更新需手动开启，只检查本项目 GitHub 正式发行版，安装由用户选择。

协议支持按具体型号与连接方式划分。除本机 VGN / Weisheng 键盘、Akko 鼠标 BLE 与蓝牙耳机外，新增厂商读取器尚需更多实体设备验证。详见[兼容性说明](compatibility.md)。
