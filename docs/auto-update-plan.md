# 应用内下载更新

1.0.5 起支持在应用内下载并打开 Windows x64 安装包。自动检查默认关闭，安装时保留交互向导。

## 使用流程

在“设置 → 通用 → 版本与更新”开启自动检查后，立即检查一次，此后每 12 小时查询 `YangYingX/Perivolt` 的 GitHub 正式发行版。只提供稳定版，不降级；相同数字版本的候选版可以更新到正式版，例如 `1.0.5-rc.7` → `1.0.5`。

发现新版后点击“下载并安装”。应用显示进度并允许取消；下载完成后验证文件大小、SHA256 和安装包格式，再保存设置、打开交互安装向导并正常退出电栖。下载、校验或打开安装器失败时保留当前程序供重试，关闭更新开关会取消正在进行的下载。

已安装版会核对当前运行目录与本用户的安装注册信息，将当前安装目录通过 `/DIR` 显式传给安装器。目录选择页仍会显示，供用户确认。自定义 `--data-dir` 会传给安装完成后的启动命令、快捷方式和此次升级保留的开机启动命令。便携运行时由安装向导确认安装位置，不直接替换 ZIP 文件。

## 下载与校验

只识别本仓库对应版本的 `Perivolt-Setup-<版本>-x64.exe` 或旧命名 `PowerHub-Setup-<版本>-x64.exe`。下载使用 HTTPS 并限制跳转主机，临时文件在大小、SHA256 和 EXE 头验证通过后才成为可执行的安装包。优先使用 GitHub Release asset 的 `digest`；缺失时读取该发行版中明确匹配安装包文件名的 SHA256 侧车或校验清单。缺少有效摘要时不能启动安装。

构建安装器会同时生成 `<安装包>.exe.sha256`。发布时应将安装包及其侧车一起上传到同一 GitHub Release；GitHub 提供的 asset digest 同样可用于校验。不使用镜像站或任意外部下载地址。

## 设置与联网

默认不检查、不下载。更新功能不发送设备诊断或个人设置；诊断上报另有独立开关。旧安装路径、设备偏好、插件开关和用户数据继续保留。安装器支持正常关闭正在使用的旧程序，不强制终止进程。

当前流程包含用户点击下载、校验和打开安装向导；后台静默安装、断点续传、便携 ZIP 自动替换及安装失败自动回滚尚未实现。
