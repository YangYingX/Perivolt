# 下一版自动下载安装计划

状态：已规划，目标 1.0.2；1.0.1 不包含以下自动下载安装功能。

## 当前升级方式

1.0.0 与 1.0.1 只有默认关闭的更新检查。开启后立即查询一次，此后每 12 小时检查本项目 GitHub 正式发行版，发现新版本时提供下载页面。1.0.1 作为正式发行发布，1.0.0 可检测到它。

用户先从托盘退出，再运行新版安装器并选择原安装目录覆盖，无需卸载或删除设置；便携版完整解压覆盖。旧版本需要手动升级一次到包含新更新器的版本，之后才能使用自动下载安装。

## 功能范围与实现顺序

1. **开关与通道**：保留自动检查开关，增加自动下载、退出后自动安装选项，默认关闭；关闭后取消相关任务。默认正式版通道，测试版由用户主动选择；完整比较版本号与预发布标识，不自动降级。
2. **下载与校验**：只获取本项目 GitHub Releases 的 Windows x64 包，经 HTTPS 下载到临时目录。核对大小和 SHA256，并用内置公钥验证发布清单签名；限制重定向来源，校验失败不执行。发布流程同步生成并签署清单，签名私钥不进入仓库或安装包。
3. **安装交互**：下载后提供“现在安装／退出后安装／稍后”。只有用户开启自动安装策略时才安排自动安装。开始安装前提交输入框及滑块编辑，原子保存设置，正常退出并释放实例锁；短时辅助进程等待退出后运行安装器，成功后重启。无需常驻更新服务或内存注入。
4. **安装路径与设置**：沿用已安装程序的真实目录，向安装器传入明确的 `/DIR`，不重新选择磁盘。保持普通用户安装，保留用户数据目录、自定义 `--data-dir`、开机启动设置、设备偏好和插件开关；目录不可写时给出手动升级入口。
5. **失败恢复**：下载或校验失败不影响旧版运行。替换前保留必要的旧程序文件，安装失败或新版启动检查失败时恢复可运行的旧程序；不覆盖或回退用户设置，不循环重试安装。实施前验证 Inno 安装器与回退步骤的边界。
6. **便携版**：区分安装版和 ZIP 模式。便携模式使用匹配的 ZIP，由临时辅助进程在退出后替换本体及随包插件；保留用户插件、数据目录和启动参数。不可写路径回退到手动解压覆盖。

全程不上传设备信息或设置。默认离线行为保持不变；用户主动开启更新相关功能后才联网。

## 完成标准

- 关闭更新功能时不创建网络请求，关闭正在下载的任务后不执行安装。
- 正式通道不会收到预发布版；版本比较涵盖从测试版到正式版以及禁止降级。
- 断网、损坏下载、错误摘要、错误签名、非允许来源均不会执行安装。
- 普通用户权限、含空格和中文的安装路径、非系统盘路径均可覆盖升级；不改变原安装位置。
- 安装前未提交的编辑、设备重新连接后的偏好、开机启动及插件开关正确保留。
- 安装失败与启动失败后仍有可运行的程序；设置不会被旧版本数据覆盖。
- 安装版及便携版分别验证，并清理临时测试文件。

本计划在下一版实施；本次发行仅包含已完成的界面、桌面卡片、配色、设置迁移与动效改进。
