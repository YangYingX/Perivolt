# 兼容性与适配范围

正式发布版本：1.0.5。协议记录更新：2026-10-21；1.0.2 新增的协议族继续保留，1.0.4 补充迈从 `3837:600A` 与狼途 LT95，1.0.5 补充下列 Akko 鼠标接收器，并修正 G502 X 接收器及迈从耳机查询。下表的代码实现与报文验证不代表对应实体设备已实读成功。

PowerHub 按硬件标识、连接方式和报告格式选择读取器。**品牌被列出不等于该品牌所有型号、所有连接方式均支持。** 下文的“已实现”表示代码与报文检查已存在；只有明确注明“本机实测”的记录才代表本轮实体设备验证。

## 本机实测

| 设备或协议 | 连接方式 | 本轮读取示例 | 证据与边界 |
| --- | --- | --- | --- |
| VGN / Weisheng 键盘 `320F:5088` | 2.4G 接收器 | 38% | 厂商电量请求与响应已实读；不推广到其他 VGN 型号 |
| Akko 蓝牙鼠标 | BLE | 41% | 标准 Battery Service 实读；与 2.4G 查询路径独立 |
| Akko 空影 TAN8 `38EE:000F`（1.0.5-rc.3） | 2.4G 接收器 | 44% | 官方 Report 04 电量查询实读；充电标志为 0；该报告不提供鼠标无线在线状态 |
| 蓝牙耳机 | 蓝牙 | 70% | Windows 当前电量属性；驱动可能保存缓存值 |

示例百分比只是当时读数，会随充放电变化。本表不包含真实蓝牙地址、设备实例路径、容器 UUID 或序列号。

## 通用读取路径

| 来源 | 实现能力 | 主要限制 |
| --- | --- | --- |
| Windows PnP 电量属性 | 从当前外设节点读取有效百分比，合并重复接口 | 属性可能为驱动缓存；蓝牙缓存仅用于本次系统确认在线的设备 |
| BLE Battery Service | 已连接设备的标准电量，以及 BAS 1.1 提供的充电状态 | 不主动连接离线设备；多电池耳机暂不自动标注左右耳和充电盒 |
| 标准 HID 电池 Feature | 描述符声明的 Battery Strength、Relative State Of Charge、Charging | 设备必须真正提供对应报告；USB 供电不等于正在充电 |
| XInput 1.4 | 原生“已耗尽、低电量、中等、充足”档位 | 无精确百分比；未知电池、有线供电不推算成电量或充电状态 |

USB 接收器存在只说明接收器连接到了电脑。提供独立在线字段的厂商协议会进一步检查无线外设状态；Akko 本次电量查询与狼途 LT95 查询没有该字段，仅显示接收器连接，不能据此声称鼠标或键盘无线在线，也不会借用离线蓝牙读数。

## 尚不能据此宣称支持的设备

- **其他 Akko 接收器**：本次只验证 `38EE:000F` 的指定厂商接口；不据此宣称全部 Akko 型号、接收器修订或有线模式已支持。
- **北通 / GameSir / Xbox**：处于 Windows 可识别的 XInput 模式且驱动返回电池信息时，可使用通用档位读取。当前没有据此提供各品牌私有精确百分比、Switch 模式或全部蓝牙模式支持。
- **ROG、其他 ATK / MCHOSE 等型号**：可先尝试通用 Windows / BLE / HID；除精确白名单命中且报文通过验证外，没有整品牌私有电量支持承诺。
- **USB 麦克风、无线麦克风及其他音频外设**：目前只有通用 Windows / BLE / HID 电量识别，未宣称支持未经验证的厂商私有麦克风电量协议。仅 USB 总线供电的设备可能根本没有电池。

## 适配优先级的依据

优先覆盖 Logitech、Razer、AULA、VGN、ATK、MCHOSE、ROG，以及北通和 GameSir 的常见 PC 连接模式。这个名单用于安排实机采样和协议验证，**不是销量排名，也不是兼容性承诺**。

2026-05-05 的 [Logitech FY2026 官方财报](https://ir.logitech.com/news/news-details/2026/Logitech-Announces-Q4-and-Full-Fiscal-Year-2026-Results/default.aspx) 报告全年销售额约 48.4 亿美元，可作为厂商规模参考，不能用来计算某类外设的销量或中国市场名次。[京东机械键盘聚合页](https://www.jd.com/hotitem/6705018db02da79929c.html) 与 [京东手柄聚合页](https://www.jd.com/hprm/670256f39745fa2494c.html) 提供品牌和商品线索，但没有统一统计区间与跨品类销量口径；页面顺序、评论数均不能直接作为精确销量榜。

## 反馈设备时需要什么

提供设备完整型号、连接模式、固件版本、VID/PID，以及“可识别但电量未知 / 电量不符 / 充电状态不符”等现象。蓝牙、2.4G、USB 应分别验证。

不要公开蓝牙地址、序列号、容器 UUID、完整实例路径或未经清理的扫描 JSON。设备重新连接偏好按系统身份保存；系统在切换连接模式或接收器槽位时分配不同身份，可能需要分别配置。
