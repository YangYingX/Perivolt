# 电栖 · Perivolt 开发预览

本分支是 1.0.2 开发预览，稳定发行版仍为 PowerHub 1.0.1。应用文件名、GitHub 地址、安装 AppId、启动项标识与默认设置目录沿用旧值，保证后续升级仍能找到旧设置。中文界面使用“电栖 / 電棲”，英文和日文界面使用 Perivolt。图标提供 SVG、16–256 像素九档 PNG 和多尺寸 ICO。

## 启动与版本

解压后双击 `Run-Preview.cmd`；预览使用 `--preview` 独立单实例入口和包内 `data` 设置目录，不会把启动请求转交给正在运行的 1.0.1。主界面左上角和通用更新区域显示包含预览后缀的版本号。重复点击同一预览入口会打开已经运行的预览面板。

## 语言

设置 → 通用 → 显示语言：简体中文、繁體中文、English、日本語，默认简体中文。选择后即时更新面板、托盘菜单、桌面卡片和内置通知，并记住选择。设备原名、自定义名称和原始硬件诊断保持原文。语言目录随包内置，切换不需要联网。

## 同一设备的不同连接方式

1. 分别通过蓝牙和 2.4G 接收器连接一次，让程序记住两种身份。
2. 在设备概览点击当前设备的“设置”，进入“设备外观”。
3. 在“关联连接方式”选择另一种身份，点击“关联为同一设备”。设置沿用下拉框中所选的那台设备；桌面固定状态会保留。
4. 后续只连接任一种模式，都显示为同一设备，共用名称、颜色、样式、提醒和排序；同时在线时采用最新的有效电量读数。
5. 点击“取消关联”可恢复独立身份，原有的两份设备配置仍保留。只有当前确认在线的设备进入概览和桌面；关联下拉框中的历史名称只用于选择关系，不会作为在线设备显示。

已有可靠的相同硬件身份（蓝牙地址、容器或实例等）仍由扫描器自动合并；没有共同身份时不靠同名、同型号或厂商号推断，以免合并两台同款外设。XInput 槽位等系统身份可能随插拔变化，不是可保证跨电脑或所有接收器稳定的序列号。本功能也不会让原本不提供电量的协议产生电量读数。

## 桌面锁定与任务栏

设置 → 桌面卡片：锁定后整个卡片窗口允许鼠标穿透，仅锁定图标上的小型解锁按钮接受点击。可点击下方桌面或应用；打开面板和隐藏卡片按钮在锁定时禁用。解锁后恢复拖动和正常操作，隐藏卡片时解锁按钮一起隐藏。

同页可独立启用“任务栏左端电量条”，选择一个在线设备，或自动选择最低电量设备；“左侧间距”用于避开开始按钮和系统小组件。电量条使用紧凑图标、名称、百分比与细进度条，按系统任务栏的明暗配色，使用真实任务栏像素边界与 DPI 定位；子窗口随父任务栏移动和隐藏。启用期间每秒检查父窗口是否更换或尺寸变化，关闭后销毁子窗口并停止检查。指定设备离线时自动隐藏。电量条通过 WPF HwndSource 创建 WS_CHILD 子窗口，父窗口为 Windows 任务栏，绘制仍在本程序进程内；不使用置顶桌面覆盖，不注入 Explorer，也不加载 DLL 到 Explorer。不修改现有任务栏控件的位置，不申请系统保留槽位，仍可用左侧间距避开已有控件。挂载失败时明确提示，不回退到悬浮层。全屏程序、任务栏自动隐藏和不同 Windows 任务栏布局下的层级仍需实机反馈。

## 整卡填充

设置 → 设备外观 → 电量样式 → 底色填充。整张卡片从左向右按电量比例填充，文字保持普通显示，不加反色描边。设备概览与桌面卡片适用；任务栏使用独立的紧凑进度条。使用所选设备的颜色节点、整体颜色不透明度，以及独立保存的“底色填充”透明度。没有精确百分比的设备保持原生档位文字，不伪造填充比例。

## 验证与交付范围

本次使用临时 WPF 检查程序验证四语言文案和参数占位符、语言切换、关联/取消关联与配置持久化、不同连接读数合并、填充像素、无描边文字、四边任务栏位置与四档缩放、锁定窗口穿透和解锁按钮命中；检查源文件用完删除。实体设备跨模式的协议电量精度仍需对应设备验证。

程序继续默认离线，任务栏和关联功能不新增网络请求。预览不包含自动下载安装；稳定更新仍由现有更新检查器提示并打开发行页。

## 启动诊断与安装兼容性

从本次预览起，安装包使用自带 .NET 运行时的文件夹部署，不再依赖单文件在启动前解压到临时目录。必须保留整套文件，不能只复制 PowerHub.exe；无需额外安装 .NET。安装完成后可直接打开面板，桌面和开始菜单快捷方式显式使用 --show。首次手动启动也显示面板，开机启动仍按托盘偏好执行。

托盘和任务管理器都没有进程时，不能归因为面板隐藏。将 Diagnose-Startup.cmd 放到 PowerHub.exe 旁运行，会记录退出码、运行时主机加载日志和标准错误。它也可单独用于排查 1.0.1，无需重置设置。日志仅写入本地，不自动上传；含用户名和路径，分享前可自行去掉这些内容。

本程序进入托管入口后的未处理启动异常会写入 %LOCALAPPDATA%\PowerHub\logs\startup.log 并显示错误提示；若目录不可写则尝试 TEMP 下的 Perivolt-logs。托管入口之前的系统/运行时加载失败需要诊断脚本的 host-startup.log 和 app-startup.txt。Windows 10 最低仍为 2004 / build 19041、x64；朋友设备是否满足要求由诊断结果确认，不能仅凭“Win10”判断。

任务栏嵌入在本机 Windows 11 验证了父子句柄、独立进程和 DPI 保持不变；它不是 Windows 10 的 DeskBand COM 扩展，也不保证所有第三方任务栏或后续系统版本均可挂载。Windows 10 实体机和资源管理器重启后的恢复仍需实测。
