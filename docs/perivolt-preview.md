# 电栖 · Perivolt 1.0.3 功能说明

1.0.3 沿用旧版的应用文件名、安装 AppId、启动项标识与默认设置目录，保证覆盖升级仍能找到旧设置。GitHub 仓库和检查更新地址改为 `YangYingX/Perivolt`；1.0.2 及更早版本需从新发行页手动下载覆盖升级。中文界面使用“电栖 / 電棲”，英文和日文界面使用 Perivolt。图标提供 SVG、16–256 像素九档 PNG 和多尺寸 ICO。

## 启动与版本

正式版完整解压后运行 `PowerHub.exe`，或使用安装器创建的快捷方式。开发预览包通过 `Run-Preview.cmd` 启动，使用 `--preview` 独立单实例入口和包内 `data` 设置目录，不会把启动请求转交给正在运行的正式版。主界面左上角和通用更新区域显示完整版本号，预览版带预览后缀。重复点击同一入口会打开已经运行的对应面板。

## 角色主题与本地立绘

从 1.0.3 起，主程序安装包和便携包不再附带“群星映色”，需单独安装可选插件。

可选“群星映色”插件内置四款游戏共 109 套角色灵感主题。插件页开启后点击“选择主题”，或进入“设置 → 通用 → 插件主题”；可按游戏筛选、按角色中文名或英文 ID 搜索。选择后立即应用并保存，启用插件本身不覆盖当前选择。内置配色及原创矢量装饰，不含游戏立绘，不需要联网。列表按可见项回收，调色板首次加载后缓存。详情见 [角色主题包](../Extensions/CharacterThemes/README.md)。

选中角色主题后，可选择独立的立绘文件夹，按主题 ID（例如 `endfield-si.png`）自动匹配；也可为当前角色单独选择 PNG/JPEG。显示开关、透明度和左中右位置按主题记忆，重置只清除当前角色的自定义设置。只异步解码当前图片，最长边最多 1600 像素，切换时丢弃过期结果；不扫描其他磁盘，不加载远程 URL 或网络共享。立绘不进入公开 GitHub 仓库、发行 ZIP 或安装程序，软件不会自动下载。

## 显示语言

设置 → 通用 → 显示语言：简体中文、繁體中文、English、日本語，默认简体中文。选择后即时更新面板、托盘菜单、桌面卡片和内置通知，并记住选择。设备原名、自定义名称和原始硬件诊断保持原文。语言目录随包内置，切换不需要联网。

## 同一设备的不同连接方式

1. 分别通过蓝牙和 2.4G 接收器连接一次，让程序记住两种身份。
2. 在设备概览点击当前设备的“设置”，进入“设备外观”。
3. 在“关联连接方式”选择另一种身份，点击“关联为同一设备”。设置沿用下拉框中所选的那台设备；桌面固定状态会保留。
4. 后续只连接任一种模式，都显示为同一设备，共用名称、颜色、样式、提醒和排序；同时在线时采用最新的有效电量读数。
5. 点击“取消关联”可恢复独立身份，原有的两份设备配置仍保留。只有当前确认在线的设备进入概览和桌面；关联下拉框中的历史名称只用于选择关系，不会作为在线设备显示。

已有可靠的相同硬件身份（蓝牙地址、容器或实例等）仍由扫描器自动合并；没有共同身份时不靠同名、同型号或厂商号推断，以免合并两台同款外设。XInput 槽位等系统身份可能随插拔变化，不是可保证跨电脑或所有接收器稳定的序列号。本功能也不会让原本不提供电量的协议产生电量读数。

## 桌面锁定与任务栏

设置 → 桌面卡片：锁定后整个卡片窗口允许鼠标穿透，仅锁定图标上的小型解锁按钮接受点击。可点击下方桌面或应用；打开面板和隐藏卡片按钮在锁定时禁用。解锁后恢复拖动和正常操作，隐藏卡片时解锁按钮一起隐藏。

同页可独立启用“任务栏电量条”，选择一个在线设备，或自动选择最低电量设备。电量条自动适配上、下、左、右四边任务栏，避让开始按钮、应用按钮和通知区域；空间变窄时收紧内容，空间不足或暂时无法识别空闲区域时隐藏并等待恢复。按住电量条可沿任务栏拖动，松开后自动记住位置；也可通过“起始偏移”微调，横向从左、竖向从上计算，单位为 DIP，仍会避开已有控件。

电量条按系统任务栏的明暗配色和缩放调整图标、设备名、电量与进度条，随任务栏移动和隐藏；指定设备离线时自动隐藏。启用期间持续检查任务栏布局，关闭后停止检查并移除电量条。不移动 Explorer 的现有控件，不申请系统保留槽位，不注入 Explorer，也不使用置顶桌面覆盖。挂载失败时明确提示。全屏程序、任务栏自动隐藏和不同 Windows 任务栏布局下的层级仍需实机反馈。

## 托盘右键菜单

1.0.3 为托盘菜单设置独立所属窗口，在系统右键通知处理完成后再打开菜单，并先处理前台焦点，避免菜单刚出现就因焦点与鼠标捕获时序被关闭。模拟菜单交互已通过，用户遇到的原始闪退场景仍待复测。

## 整卡填充

设置 → 设备外观 → 电量样式 → 底色填充。桌面卡片从左向右按电量比例填充；设备概览使用淡色背景及底部细进度条，文字保持普通显示，不加反色描边。任务栏使用独立的紧凑进度条。使用所选设备的颜色节点、整体颜色不透明度，以及独立保存的“底色填充”透明度。没有精确百分比的设备保持原生档位文字，不伪造填充比例。

充电时，电量图形和底色填充样式均显示闪电标记，填充区域增加流光与呼吸动效；概览优先显示“正在充电”，下方单独提示低电量提醒已暂停。动效遵循全局开关与每设备幅度设置，隐藏或停止充电时停止，关闭动效后保留静态充电标记。

## 验证与交付范围

预览阶段使用临时 WPF 检查程序验证四语言文案和参数占位符、语言切换、关联/取消关联与配置持久化、不同连接读数合并、填充像素、无描边文字、四边任务栏位置与四档缩放、锁定窗口穿透和解锁按钮命中；检查源文件用完删除。Windows 11 本机任务栏挂载和模拟托盘菜单交互已通过；Windows 10 实机、用户遇到的原始菜单闪退场景与实体设备跨模式的协议电量精度仍需对应环境验证。

程序继续默认离线，任务栏和关联功能不新增网络请求。预览不包含自动下载安装；稳定更新仍由现有更新检查器提示并打开发行页。

## 启动诊断与安装兼容性

从本次预览起，安装包使用自带 .NET 运行时的文件夹部署，不再依赖单文件在启动前解压到临时目录。必须保留整套文件，不能只复制 PowerHub.exe；无需额外安装 .NET。安装完成后可直接打开面板，桌面和开始菜单快捷方式显式使用 --show。首次手动启动也显示面板，开机启动仍按托盘偏好执行。

托盘和任务管理器都没有进程时，不能归因为面板隐藏。将 Diagnose-Startup.cmd 放到 PowerHub.exe 旁运行，会记录退出码、运行时主机加载日志和标准错误。它也可单独用于排查 1.0.1，无需重置设置。日志仅写入本地，不自动上传；含用户名和路径，分享前可自行去掉这些内容。

本程序进入托管入口后的未处理启动异常会写入 %LOCALAPPDATA%\PowerHub\logs\startup.log 并显示错误提示；若目录不可写则尝试 TEMP 下的 Perivolt-logs。托管入口之前的系统/运行时加载失败需要诊断脚本的 host-startup.log 和 app-startup.txt。Windows 10 最低仍为 2004 / build 19041、x64；朋友设备是否满足要求由诊断结果确认，不能仅凭“Win10”判断。

收到的 1.0.1 日志报 `Your Windows doesn't fully support CET`，退出码为 `-2146233082`（`0x80131506`）。1.0.2 通过项目的 `CetCompat=false` 取消本程序的 CET 兼容标记，不修改系统防护策略；这项兼容构建仍待受影响的 Windows 10 电脑复测。依据：[微软的 CET 兼容性说明](https://learn.microsoft.com/en-us/dotnet/core/compatibility/interop/9.0/cet-support)。

任务栏嵌入在本机 Windows 11 验证了父子句柄、独立进程和 DPI 保持不变；它不是 Windows 10 的 DeskBand COM 扩展，也不保证所有第三方任务栏或后续系统版本均可挂载。Windows 10 实体机和资源管理器重启后的恢复仍需实测。
